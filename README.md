# Бот для анонимных вопросов

Бот принимает текст в личных сообщениях и отправляет его двум администраторам без имени, юзернейма и ссылки на профиль автора. Ответь на сообщение бота через Telegram Reply («Ответить»). Бот отправит текст ответа автору и обновит статус в обоих админских чатах. Если админы ответят одновременно, бот отправит первый обработанный ответ. 

## Запуск на Windows

Открой PowerShell в папке с файлами проекта. Понадобится Python 3.12.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env

```

1. Создай бота командой `/newbot` в [@BotFather](https://t.me/BotFather). Впиши токен в `BOT_TOKEN` в файле `.env`.
2. Запусти `.\.venv\Scripts\python.exe BotFemb.py`. Попроси @MARKtManager и @Minifemb открыть бота и отправить `/id`. Эта команда показывает ID отправителя в его личном чате.
3. Останови бота через Ctrl+C. Впиши оба полученных ID через запятую в `ADMIN_IDS` и запусти бота снова той же командой.
4. Отправь вопрос с обычного аккаунта. Проверь, что он появился у обоих администраторов, а после ответа одного админа изменились оба статуса и автор получил ответ.

В локальном режиме бот работает, пока запущен Python. Связь между вопросами и ответами хранится в файле `bot.sqlite3`.

## Бесплатный хостинг на Render с базой Neon

1. Создай базу PostgreSQL на [Neon Free](https://neon.com/blog/neon-free-plan-1-gb-per-project). Скопируй строку подключения.
2. Загрузи файлы проекта в репозиторий GitHub. Файл `.env` и локальная база исключены через `.gitignore`.
3. На [Render](https://render.com/docs/free) создай **Web Service**, подключи репозиторий и выбери **Python 3** и **Free**. Build Command — `pip install -r requirements.txt`. Start Command — `python BotFemb.py`. Для Health Check Path укажи `/`.
4. В разделе **Environment** добавь `BOT_TOKEN`, `ADMIN_IDS`, `DATABASE_URL` со строкой подключения Neon и `WEBHOOK_SECRET` со случайным секретом. Сгенерировать его можно командой `.\.venv\Scripts\python.exe -c "import secrets; print(secrets.token_urlsafe(32))"`.
5. Останови локального бота и запусти деплой. Бот возьмёт публичный адрес из `RENDER_EXTERNAL_URL` и сам зарегистрирует вебхук. Отправь новый вопрос для проверки. Связи с вопросами, заданными при локальной проверке, останутся в локальном файле SQLite.

Render Free засыпает после 15 минут без запросов. После паузы пробуждение может занять около минуты. PostgreSQL хранит связь вопросов с ответами между перезапусками.
